# Como publicar a home do seu perfil

O GitHub mostra no seu perfil o `README.md` de um repositório **público com o mesmo nome do usuário**.

1. Crie um repositório público chamado **`VitorFariasVF`** (em github.com/new). Marque "Add a README".
2. Copie para ele, mantendo as pastas:
   - `profile/README.md` → `README.md` (substitui o gerado)
   - `profile/assets/` → `assets/`
3. Pronto: abra github.com/VitorFariasVF.

Quando uma ferramenta ficar pronta, edite a linha dela no `README.md`: troque "EM CONSTRUÇÃO" por "DISPONÍVEL", o link para o do Pages, e atualize o contador "1 PRONTA · 2 EM CONSTRUÇÃO".

Os banners têm versão escura e clara e trocam sozinhos conforme o tema do visitante.
O GitHub não carrega fontes externas: a serifa é a do sistema (Iowan, Palatino ou Georgia).
